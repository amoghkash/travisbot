Using XPadNeo and bluetooth

| :------- | :------: | :------: |
| Left Joystick X Direction | Code 0 | -32767 to 32767 |
| Left Joystick Y Direction | Code 1 | -32767 to 32767 |
| Left Trigger | Code 2 | -1023 to 1023 |
| Right Joystick X Direction | Code 3 | -32767 to 32767 |
| Right Joystick Y Direction | Code 4 | -32767 to 32767 |
| Right Trigger | Code 5 | -1023 to 1023 |
